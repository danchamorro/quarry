# Quarry 0.1.0 beta 2

**Published October 6, 2026.** Broader validation is still in progress.
[GitHub prerelease](https://github.com/danchamorro/quarry/releases/tag/v0.1.0-beta.2).

## Changes since beta 1

- Horizontal and vertical lines now delineate the grid's cells, including
  headers and row numbers.
- Expanded columns and auto-fit can display long values beyond the previous
  120-character preview. Grid previews remain bounded at 16,384 characters;
  copying and editing retain the full value.
- The window identifies Quarry as a beta. **File menu → About & Feedback…**
  shows the version, build and source revision, copies build details, and links
  to the bug form and user guide.

## Compatibility and limits

The project targets Apple Silicon on macOS 26 and 27. This archive has been
tested only on **macOS 27.0.1 (26A434)**; macOS 26 validation is outstanding for
this archive. Prior beta 1 evidence is historical, not a build 140 pass.
Intel Macs, Linux desktop and Windows are outside the packaged beta scope.

Complete connected workflows, wide-grid accessibility, large-file GUI and
temporary-storage recovery remain unverified for this archive. First launch
after a browser download with quarantine, first launch in a clean environment,
and first launch while offline are also unverified. The earlier beta's CJK
font-rendering limitation has not been retested. Use disposable data during
testing; clear filters before editing, and save or discard edits before filtering.
Undo history is bounded. See the [user guide](../USER_GUIDE.md).

## Installation and feedback

Download the [signed Apple Silicon archive](https://github.com/danchamorro/quarry/releases/download/v0.1.0-beta.2/Quarry-0.1.0-beta.2-macos-arm64.zip)
and verify the SHA-256 above or the attached `SHA256SUMS` file. Save work and
quit Quarry before replacing it; retain the previous app for rollback. Extract the ZIP, move Quarry.app to Applications
and open normally. Report blocking messages without bypassing Gatekeeper.
There is no automatic updater. To roll back, quit Quarry and restore the
previous app.

Use **About & Feedback… → Copy build details** when filing a
[bug report](https://github.com/danchamorro/quarry/issues/new?template=bug_report.yml).
Include the exact macOS version, steps and a synthetic reproduction. Remove
private data from public reports. Quarry remains free and open source under
MIT OR Apache-2.0, without activation, paid tiers or telemetry.
