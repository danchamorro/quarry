# Quarry 0.1.0 beta 3

**Published November 21, 2026.** Broader validation is still in progress.
[GitHub prerelease](https://github.com/danchamorro/quarry/releases/tag/v0.1.0-beta.3).

## Changes since beta 2

- **Native macOS desktop redesign (light mode)**: Unified toolbar and title bar,
  native macOS menu bar wired to shortcut events, system fonts with tabular
  digits for numeric cells, light Aqua appearance even in macOS Dark mode, and
  clearer VoiceOver tab labels.
- **Document tabs**: Open up to eight independent delimited files with per-tab
  edits, selection, filters, background jobs, and safe close/quit prompts.
- **Simplified Join Files**: Join two saved or open unsaved delimited files on
  one to sixteen key column pairs in a single-screen workflow with **Left**,
  **Inner**, **Right**, and **Full** join controls, output column
  selection/reordering, optional **Preview**, and one-click **Join…** that
  analyzes, writes, and opens the joined result in a new tab.
- **Combine Files**: Combine two or more matching saved delimited files in
  chosen order into a new file with record validation, progress, and
  cancellation.
- **Gzip-compressed files (`.gz`)**: Open `.gz` delimited files read-only with
  immediate first-row display, bounded one-pass temporary decompression,
  member/CRC verification, and **Inspect File** support.
- **Automatic column discovery**: Background indexing automatically discovers
  wider rows (up to 65,536 view columns) and updates the column count in the
  footer.
- **Editing, cleanup, and sorting**: Row and column insertion, **Clean Up
  Columns** (trim Unicode whitespace, collapse repeated spaces, case conversion,
  fill empty cells), subtle whitespace indicators with an all-whitespace toggle,
  multi-column stable sorting, **Date / time** sorting, filtering of unsaved
  edits in place, and saving reordered columns through **Save As…**.
- **Encodings, inspection, and privacy**: Broader Unicode (UTF-8/UTF-16 with
  native BOM handling) and legacy CSV encodings, **Inspect File** with validated
  recovery copies, and hardened owner-private temporary spill and export
  staging.

See [`CHANGELOG.md`](../../CHANGELOG.md) for the complete history.

## Compatibility and limits

The project targets Apple Silicon on macOS 26 and 27. This archive has been
tested only on **macOS 27.2.1 (26B131)**; macOS 26 validation is outstanding for
this archive. Prior beta 1 and beta 2 evidence is historical, not a build 167
pass. Intel Macs, Linux desktop, and Windows are outside the packaged beta
scope.

Complete connected workflows, wide-grid accessibility, large-file GUI,
temporary-storage recovery, first launch after a browser download with
quarantine, first launch in a clean environment, and first launch while offline
remain unverified for this exact archive. Use disposable data during testing;
undo history is bounded. See the [user guide](../USER_GUIDE.md).

## Installation and feedback

Download the [signed Apple Silicon archive](https://github.com/danchamorro/quarry/releases/download/v0.1.0-beta.3/Quarry-0.1.0-beta.3-macos-arm64.zip)
and verify the SHA-256 above or the attached `SHA256SUMS` file. Save work and
quit Quarry before replacing it; retain the previous app for rollback. Extract
the ZIP, move `Quarry.app` to Applications, and open normally. Report blocking
messages without bypassing Gatekeeper. There is no automatic updater. To roll
back, quit Quarry and restore the previous app.

Use **About & Feedback… → Copy build details** when filing a
[bug report](https://github.com/danchamorro/quarry/issues/new?template=bug_report.yml).
Include the exact macOS version, steps, and a synthetic reproduction. Remove
private data from public reports. Quarry remains free and open source under MIT
OR Apache-2.0, without activation, paid tiers, or telemetry.
