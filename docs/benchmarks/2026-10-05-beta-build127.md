## Signed-ZIP 12 GB GUI check on macOS 27.0.1

Capture became usable temporarily, allowing the same signed build 127 to open
the Hacker News fixture through the native picker. The grid displayed rows
while indexing was still at 78.4%. After indexing, entering row 28,737,557
showed the final page, rows 28,737,507–28,737,557, with the expected last ID
`7536640` and the full record count.

The searchable column picker selected score (source column 12) and type
(source column 3). Score >= 100 AND type Equals story produced progressive
matches and then exactly 128,222 matches. Export through the native Save
dialog and storage-preparation dialog produced 54,128,598 bytes. Every decoded
record and the header matched the independent Python CSV/Decimal oracle;
the SHA-256 matched the CLI export above. The UI reported export complete.

A second export to a new disposable destination was cancelled after visible
progress. The UI reported cancellation, retained the 128,222 active matches,
and no destination or `.quarry*` export temporary file remained. The full
source SHA-256 was rechecked and remained unchanged.

One-second process sampling began after initial indexing had started and
continued through navigation, filtering, export, cancellation and closing.
The highest observed RSS was 203,948,032 bytes (194.5 MiB). This is a sampled
result on this fixture, not a full-launch peak or a general memory bound.
The isolated working folder remained empty; export temporary files use the
destination directory, whose peak disk usage was not sampled. Selected-folder
sort/Undo retention and insufficient-space recovery still need acceptance.

The grid was observed in both approximately 950- and 1908-pixel-wide windows.

returned white images and a window-position error again. Command-Q closed the
