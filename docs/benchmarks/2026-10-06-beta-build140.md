## VMPal update and native workflow

was transferred over the local VM network and its SHA-256 matched. Strict
signature and Gatekeeper assessment passed in the guest. Commands ran without
elevation. The previous installed build 127 was closed, archived, extracted and
signature-checked as a rollback backup before replacing it with build 140.

The installed app passed these checks with a four-record, three-column
synthetic CSV:

  file and exited. The 257-byte output matched the independently constructed
  expected bytes, including the long value, quoted comma and embedded newline.
- Reopened that saved file in the installed app; the edited ID was visible and

## Publication verification

GitHub release `405172386` is a public prerelease. Its tag points to the exact
clean source above. The uploaded ZIP is 3,629,137 bytes and GitHub's SHA-256
digest matches the frozen candidate. An anonymous HTTPS download of the ZIP
and `SHA256SUMS` passed `shasum -a 256 -c SHA256SUMS`; the ZIP's bytes and hash
match the identity table. The release contains those two assets, without
rebuilding or changing the signed app. Publication logs are retained locally
under `target/beta-publication/`.

This verifies public asset delivery, not browser quarantine or native launch
of a browser-downloaded copy. Those remain separate acceptance checks.
