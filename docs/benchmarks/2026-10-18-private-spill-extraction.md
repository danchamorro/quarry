# Private spill extraction regression check

Date: 2026-10-18. Tracks [#119](https://github.com/danchamorro/quarry/issues/119), the storage foundation for [#71](https://github.com/danchamorro/quarry/issues/71).

## Environment and method

- VMPal macOS VM, Apple M3 Max (Virtual), 16 GiB RAM.
- macOS 27.0.1 (26A434), Rust 1.88.0, release profile, locked dependencies.
- Baseline: c2e138f40a73c8b65009f68901434093cf18b8ed. The baseline CLI was rebuilt and copied before changing Rust sources. Candidate: this spill-extraction change.
- One synthetic UTF-8 CSV with a header, 2,000,000 rows and 514,000,012 bytes. Row i (zero based) has three fields: four-digit key (i * 73) % 4096, ten-digit ordinal i, and 240 ASCII x characters. Records use LF.
- Two warm runs per operation, sequential baseline then candidate, on the VM filesystem. No OS cache eviction. No build or test workload ran during the timed operations. /usr/bin/time -l records process RSS; elapsed time includes process launch.
- Text sort uses column 1 ascending, header first row. Duplicate removal uses column 1 with case matching and writes retained rows. Both use the fixture directory for temporary storage and --cache-state warm.

## Results

Seconds are means of two runs. RSS and temporary disk are maximum observed bytes, shown as baseline / candidate.

| Operation | Baseline seconds | Candidate seconds | RSS bytes | Peak temporary bytes |
| --- | ---: | ---: | ---: | ---: |
| sort | 5.198 | 5.036 | 33,128,448 / 33,193,984 | 1,106,867,040 / 1,106,867,040 |
| duplicates | 2.056 | 2.067 | 31,948,800 / 31,916,032 | 1,122,869,760 / 1,122,869,760 |

Both sort outputs match an independent SHA-256 oracle generated by grouping the arithmetic keys and enumerating source ordinals in stable order:

437547ce6b716f784315c03d53fe3ddb4e998d7e51b9d28679e4e237de475801

All four duplicate-removal outputs contain 4,096 retained rows and have the same SHA-256:

0d0dcb733bc205339d0b59236a4e0179bd684388e383e7567fda87e697872b55

Every operation reported the source size unchanged. No spill directories remained after completion. Timing differences in two warm runs are insufficient for a speed claim; this check found no material performance or disk-use regression.

## Correctness checks and limits

All 542 workspace tests pass, including forced-small-budget sort/duplicate cases, source conflicts, cancellation, malformed sort frames and inherited macOS ACL checks. Six new shared-storage tests cover exact frame bytes, separate header/body consumption, empty and truncated frames, declared size rejection before payload reads, unique workspace naming, cleanup, and owner-only permissions. Formatting, all-target/all-feature Clippy, and the workspace release build pass.

This fixture is smaller than VM RAM and exercises the existing operations. It does not establish join scalability, duplicate-group skew handling, or the future 512 MiB join budget. Those remain separate acceptance work under #71.
