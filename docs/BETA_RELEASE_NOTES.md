# Quarry beta release notes

The current public prerelease is **[Quarry 0.1.0 beta 3](releases/v0.1.0-beta.3.md)**,
build **167**, published November 21, 2026.

Beta 3 adds the native macOS light-mode redesign, document tabs, simplified
single-screen **Join Files**, **Combine Files**, read-only `.gz` support,
automatic column discovery, row/column insertion, **Clean Up Columns**,
whitespace indicators, multi-column and **Date / time** sorting, broader
encodings, and **Inspect File** with validated recovery copies. Read its
versioned notes for the exact archive checksum, installation steps, and
validation limits.
