# Quarry beta release notes

The current prerelease is **[Quarry 0.2.0 beta 3](https://github.com/danchamorro/quarry/releases/tag/v0.2.0-beta.3)**,
published November 26, 2026. The 0.2.0 series is the GPU-accelerated GPUI beta
for macOS (Apple Silicon) and Linux/Omarchy (`.tar.gz` for `x86_64` and
`arm64`).

[`CHANGELOG.md`](../CHANGELOG.md) and the generated GitHub Release body are the

validation limits. Versioned notes under [`releases/`](releases/) are kept for

## 0.1.0 beta series (historical, egui)

Beta 3 (build 167, November 21, 2026) was the final pre-GPUI macOS snapshot. It
added the native macOS light-mode redesign, document tabs, simplified
single-screen **Join Files**, **Combine Files**, read-only `.gz` support,
automatic column discovery, row/column insertion, **Clean Up Columns**,
whitespace indicators, multi-column and **Date / time** sorting, broader
encodings, and **Inspect File** with validated recovery copies.
